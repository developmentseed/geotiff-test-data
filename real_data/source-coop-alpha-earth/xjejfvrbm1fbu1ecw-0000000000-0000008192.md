# source.coop Alpha Earth

A small window of a single file (specifically s3://us-west-2.opendata.source.coop/tge-labs/aef/v1/annual/2024/13N/xjejfvrbm1fbu1ecw-0000000000-0000008192.tiff) from the [source.coop version of Google's Alpha Earth embeddings](https://source.coop/tge-labs/aef), licensed CC-BY 4.0.
The AlphaEarth Foundations Satellite Embedding dataset is produced by Google and Google DeepMind.

Highlights:

- Flipped y-axis (this is a bug/issue with the data)
- int8
- 64 bands

From a local file (you could do this directly from s3 as well):

```sh
gdal raster clip \
    /vsis3/us-west-2.opendata.source.coop/tge-labs/aef/v1/annual/2024/13N/xjejfvrbm1fbu1ecw-0000000000-0000008192.tiff \
    real_data/source-coop-alpha-earth/xjejfvrbm1fbu1ecw-0000000000-0000008192.tif \
    --window 0,0,10,10
```
